- `LC_UNIXTHREAD` entries do not need absolute-address mmap support in `macho-exec`; translating the stored entry VM address through the mapped segment ranges is enough for both native `call_entry` and interpreted `call_entry_interpreted`.
- TLV block sizing in `macho-exec` must use the full address span of `S_THREAD_LOCAL_*` sections and copy `__thread_data` by section-relative offsets; summing `__thread_data` and `__thread_bss` sizes misses alignment gaps and can corrupt Rust lazy TLS state.
- The checked-in x86_64 `WezTerm.app` slice has 42 TLV descriptors, a contiguous TLV block (`span == naive_sum == 0x6a0`), and a lazy bind to `__tlv_atexit`; if it still fails after TLV span fixes, bias toward destructor registration rather than layout gaps.
- Current-source Docker runs showed the `_ioctl` shim fix is real: WezTerm now successfully `ioctl(FIOCLEX)`, `bind`, and `listen` on its GUI Unix socket before the next crash.
